HELPLINE KOREA / COPY REVIEW / 2026.10.13

짧게 나누고,
필요한 뜻은 그대로.

사이트 문구를 ASD-STE100의 문장 원칙으로 검토했습니다. 영어는 STE 구조를 참고한 후보, 한국어는 같은 원칙을 적용한 쉬운 문장입니다. 원문과 수정안, 유지한 이유를 함께 비교할 수 있습니다.

반영 전 작성한 비교 기록 · 적용 내역 별도 기록
ASD-STE100은 영어 기술문서 표준입니다. 이 보고서는 승인 어휘·품사·의미를 전수 검사한 적합성 판정이 아닙니다. 실제 반영 결과는 아래 적용 내역에서 확인하세요. 한국어에 STE 적합 판정을 내리지 않습니다.

어디에 적용하면 좋은가

연락·신청 안내에 우선 적용

조건, 행동, 결과를 한꺼번에 넣은 문장을 나누면 다음에 할 일이 선명해집니다. 바우처 요건, 긴급 연락, 상담 신청, 오류 안내에서 효과가 큽니다.

  • “연계됩니다”처럼 주체가 숨은 표현을 구체화합니다.
  • 전화번호·시간·횟수·휴무·자격 조건을 남깁니다.
  • 관리자용 Notion 안내를 이용자가 할 수 있는 안내로 바꿉니다.

공감·위기 질문에는 선택적으로 적용

“울거나 말이 멈춰도 괜찮습니다” 같은 문장은 유지했습니다. 이용자가 말할 첫마디도 지시문처럼 바꾸지 않았습니다.

  • “할 수 있다”를 “해야 한다”로 일괄 변경하지 않습니다.
  • 기본 비밀보장, 예외, 가능성을 지우지 않습니다.
  • 문장이 짧아져도 문단 전체는 더 길어질 수 있습니다.

영어 페이지에도 한국어 기관 설명이 표시됩니다. 이 보고서는 표시된 원문의 언어별로 검토합니다. 한국어 원문 전체를 영어로 새로 번역한 작업은 아닙니다.

문장 길이의 변화

완결 문장이 있는 본문·메타 설명을 대상으로 계산했습니다. 문장 분리는 마침표·물음표·느낌표 다음 공백, 영어 단어 수는 정규식 기준의 근사치입니다. 표준의 전문 명사·숫자 계산법과 다를 수 있습니다. 한국어 60글자는 보고서의 관찰 기준일 뿐 STE 규칙이 아닙니다. 수치는 이해도나 표준 적합성을 증명하지 않습니다.

검토 기준·범위·남은 확인 사항

참고한 STE 원칙

Issue 9(2025-01)를 기준으로 한 문장에 한 내용, 능동형, 조건 우선, 일관된 용어를 참고했습니다. 영어 절차 지시문은 20단어, 설명문은 25단어 이내라는 기준을 참고하되, 공감·대화 예시에 기계적으로 강제하지 않았습니다.

표준은 문장 길이뿐 아니라 승인 어휘의 의미와 품사, 분야별 전문 용어 사용도 다룹니다. 사전 대조와 분야 전문가 검토 없이 “STE 준수”라고 표시해서는 안 됩니다.

수집 범위

    비교 시 주의할 점

    • 수정안은 실제 이용자의 이해도·위기 선별 응답에 대한 실험을 거치지 않았습니다.
    • 기관 원문과 SEO 설명의 자격 범위·보장 강도가 다른 곳은 개별 검토 메모로 남겼습니다.
    • 생략된 주체를 상담원이나 기관으로 명시한 안은 실제 절차와 대조해야 합니다.
    • 가이드 링크, 길어진 메뉴 이름은 실제 UI 적용 시 별도로 확인해야 합니다.
    • 시간 구간의 줄바꿈을 추출 과정에서 잃은 2건은 복원했습니다. 실제 화면의 겹침 문제로 세지 않았습니다.

    숫자 변경 확인

      위 항목 외에는 원문·수정안의 숫자 토큰을 대조했습니다. 숫자가 같다는 사실만으로 의미 보존이 입증되지는 않습니다.

      용어 정리 후보

      아래 용어는 이 사이트의 일관성을 위한 제안입니다. STE 공식 사전의 승인 목록이 아닙니다.

      실제 적용 내역기관 데이터 적용 내역전체 비교 JSON원문·위치 목록수정안 매핑

      원문 ↔ 수정안

      검토 단위는 문장만이 아니라 문단·제목·버튼·시간·접근성 템플릿입니다. 동일 문구는 합쳤고, 전체 문장과 소스의 부분 문구가 함께 있는 경우에는 중복 적용 주의를 표시했습니다.

      이 페이지는 로컬 비교 보고서이며 외부 추적·전송을 하지 않습니다. 인쇄는 현재 필터의 현재 페이지에 표시된 항목만 포함합니다. 전체 항목은 JSON에서 확인할 수 있습니다.
